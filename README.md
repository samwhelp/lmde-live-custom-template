## Live Account

| Account  | Value  |
| -------- | ------ |
| Username | `live` |
| Password | `live` |


To change the password for the current account, you can run the following command:

``` sh
sudo passwd $(whoami)
```


To remove the password for the current account, you can run the following command:

``` sh
sudo passwd -d $(whoami)
```
